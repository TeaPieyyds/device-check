# 设备体检（Device Check）

一个**只读、本地、不联网**的安卓应用安全自查小工具。

> 不杀毒、不下结论、不上传数据。它只负责把手机上装了什么，**用你看得懂的话讲清楚**。

---

## 它要解决什么问题

网上流传的"某某病毒伪装成系统服务、无法卸载、窃取隐私"之类的恐吓信息，
往往让普通用户陷于恐慌，进而做出**破坏性操作**（误删系统应用、盲目恢复出厂、把密码交到钓鱼页面）。

本工具的思路完全不同：

- **只呈现事实**：把真实的应用列表、权限、设备管理员、无障碍服务、开机自启列给你看
- **不制造恐慌**：命中白名单的给出人话解释；不认识的，**老实说"我不认识"**
- **把判断权交出去**：不认识的项，一键分享给 AI（豆包 / DeepSeek 等）或亲自打开看看
- **操作防手滑**：删除按钮要连点 3 次、安全要连点 2 次，且两个按钮左右分离

---

## 功能

| 功能 | 说明 |
|---|---|
| 应用清单 | 读取全部应用（含系统应用） |
| 白名单识别 | 系统包 / 厂商包 / 主流应用，命中即给中文解释 |
| 未识别项 | 提供【分享给 AI】【打开看看】两个出口 |
| 用户判定 | 【安全】(2 连击，标记后从列表移出) / 【删除】(3 连击，跳转系统卸载页) |
| 执行日志 | 底部实时日志，右上角一键切换 **人话 / 原样** 两种视角 |
| 多线程扫描 | 各项检查并行执行，互不等待 |

---

## 设计原则

1. **只读**。本应用**不执行任何删除、卸载、修改操作**。删除按钮只跳转系统卸载页，处置与否由系统决定。
2. **不联网**。所有检查在本地完成，不上传任何数据。（`INTERNET` 权限仅用于系统分享面板。）
3. **不猜测**。不认识的就说"不认识"，不编造"疑似病毒"之类的模糊判断。
4. **防误触**。高风险操作需要多次点击，且按钮间距最大化。

---

## 技术栈

- Kotlin + 传统 View（XML 布局），**刻意不用 Compose**，以保持极小体积
- [Shizuku](https://shizuku.rikka.app/) 提供无 Root 的 shell 能力
- 无任何第三方运行时依赖（Shizuku 与 androidx 之外）
- Release 开启 R8 混淆 + 资源压缩

---

## 环境要求

- Android 7.0 (API 24) 及以上
- 已安装并运行 [Shizuku](https://shizuku.rikka.app/)，并授权本应用

> 没有 Shizuku 也能安装，但无法读取完整的系统级信息。

## 构建

### 本地构建

```bash
./gradlew :app:assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

### GitHub Actions（推荐）

推送到 `main` 分支后自动构建，在仓库 **Actions** 页面下载 Artifacts。
